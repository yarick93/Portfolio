I am highly comfortable with modern CSS layout systems to create flexible user interfaces. I use Flexbox as my primary tool for one-dimensional layouts, alignment, and spacing. For more complex, two-dimensional layouts, I implement CSS Grid to build structured and responsive page layouts.
